# Examples

## Al-Zn

binary system with a miscibility gap. The initial TDB is built from MLIP calculations.

## Cu-Mg

binary system with laves phase (multi-sublattice). The initial TDB is built from MLIP calculations.

## Ru-Si

binary system with stable phase Ru2Si not appear in the initial phase diagram.

## K-Na

binary system, with partial known phase equilibrium composition for solid-liquid phase equilibrium.

## Al-Mo-Si

optimization of a ternary system with more than 100 parameters.

## Au-Cu

optimization of EAM potential from desired (simplified) phase equilibria.

## Cr-Fe

binary with magnetic contribution. In this case, initial parameters are randomly initialized.
